# easy-stock 量化交易系统 — 系统说明文档

版本: 2026-10-02 ｜ 策略版本 strategy.yaml v1.3 ｜ 适用: A股 / 美股 / 数字货币三市场

---

## 1. 系统是什么

一套自研的"感知 → 规则 → 模拟验证"量化交易系统。用户出交易感知,经评估后编码成 P 系列规则写入 `strategy.yaml`,
由三套独立模拟盘按规则机械执行、攒样本,每周一复盘归因迭代。**模拟盘只认 strategy.yaml 和决策日志,不认聊天里的临场情绪。**

设计目标(2026-10-01 立项):2026 年 10–12 月盈利 30 万。分工:用户负责执行纪律(买入次日盈利拉升先卖 2/3),
系统负责提高"买入次日盈利"的概率。

## 2. 总体架构

```
数据源(新浪/东财/财联社/开盘啦/腾讯/Yahoo/Kraken)
        │ 批量节流(同花顺/东财批量≥30分钟间隔)
        ▼
Go 数据后端 :20081 (仅本机 loopback) ← A_STOCK_TOKEN,配置 ~/workspace/easy-stock-service/.env
        │
        ▼
Python 策略层 ~/workspace/easy-stock-service/*.py
   ├─ 数据底座: bars.py(CN) / bars_us.py(US) / bars_crypto.py(CRYPTO),sqlite 落盘 data/
   │   └─ 读一次对齐一次: get_bars 唯一读口; ensure_bars 查缺口只拉一次(防重复、防密集请求)
   ├─ 感知层: sentiment.py(盘前/盘中情绪) / regime.py(大环境) / sector_leader.py(板块龙头)
   ├─ 决策层: paper_trade.py(三市场统一信号链) + strategy.yaml(全部参数与 P 规则)
   └─ 推送层: push.py → 企业微信群机器人(唯一通道),每条必 @在路上
        │
        ▼
Web 工作台 :20073 (vite,仅本机) ← ~/workspace/easy-stock-web
```

## 4. 三套独立模拟账本

| 市场 | 账本 | 初始资金 | 规则要点 |
|---|---|---|---|
| A股 CN | logs/paper_ledger.json | RMB(按 strategy.yaml) | T+1,买入日不可卖 |
| 美股 US | logs/paper_ledger_us.json | USD 100,000 | T+1(美股日历锁一天),1股起 |
| 数字货币 CRYPTO | logs/paper_ledger_crypto.json | USD 100,000 | T+0,24×7,UTC 自然日,双边 0.1% 手续费 |

三账本完全隔离,参数独立(crypto_ 参数不污染股票参数)。统一决策门 `decision_gate` 当前为 shadow 模式:
只记录各因子原值不干预,攒 20–30 笔干净样本后再定是否转强制执行。

熔断:单日已实现亏损 ≥3% 自动拉起 kill switch,停 P8/P24/P18 新开仓(卖出/网格/轮动照常)+企业微信告警。

## 5. 策略规则摘要(P1–P28)

- **P1–P7**: 基础感知(破位纪律 P6、翻转进击 P7 等,源于北汽蓝谷复盘)
- **P8**: 早盘买入四条件(站上1日VWAP×1.005 + 量价齐升 + 偏离<2.5% + 盘中VWAP≥3日VWAP)+ fail-closed
- **P9–P14**: 情绪/网格/轮动相关
- **P15**: 板块龙头换仓双轨(证伪先行;强行换入需连续结构+L2确认)
- **P16**: 买回计划(所有 SELL 强制带 buyback_plan)
- **P17**: 买入次日下杀即走(错误单纪律)
- **P18**: 止盈后补回(站上VWAP×1.005+量价齐升+偏离<2.5%)
- **P19**: 加速大阳减半/诱多确认清仓
- **P20**: 保本出局(曾被套后回成本±1%减半)
- **P21**: 控盘板块识别(20天波动率<1.5%+无大K+与指数低相关→网格跳过强者)
- **P22**: 龙头早发现(涨跌不对称/异动高点抬升/OBV黄白线资金环;L2 需资金一票通过)
- **P23**: 买入必带预期(5天/3天创新高,普通单目标+2%);不及预期平仓;大阳买卖点(dayang.py)
- **P24**: 大阳跟随单(近3日大阳+多重确认,半仓,P23预期3天)
- **P25**: 趋势门(1日VWAP>3日VWAP>5日VWAP 且昨收站上MA20,否则不开仓)
- **P26**: 板块四维确认(强度+热度+力度+量能,P24 要求≥50分)
- **P27**: 最低半仓(无系统性风险且仓位<50%时单笔1.5倍);系统性风险=大盘情绪AND持仓VWAP双确认
- **P28**: 每日轮动T(仅 P25 通过才做T;节奏按周)

完整参数与阈值以 `strategy.yaml` 为准,改动走 changelog。

## 6. 每日运行链路(A股,交易日)

08:30 盘前关注池(structure-scan) → 08:35 盘前情绪(premarket-sentiment) → 09:00 预开仓计划(preopen-plan)
→ 09:15 集合竞价扫描(auction-scan,采样至09:27) → 09:27 竞价预挂单(preopen-buy,只生成订单不买入)
→ 09:30 开盘执行(09:45前窗口) → 10:05 早盘确认(morning-signal,严格P8)
→ 盘中每15分钟扫描(intraday-scan)/30分钟情绪(intraday-sentiment)
→ 15:35 日线归档(bars-daily-append,15:30后取终值) → 15:40 模拟盘结算(paper-settle)
→ 16:05 漏斗日报(funnel-count,10-08起) → 03:00 数据维护(svc-maintenance)

美股:05:15 日K归档 → 05:35 结算;22:00 早盘信号。币圈:每4小时信号(UTC 00/04/08/12/16/20);00:10/00:25归档结算。

每周一 20:00 周复盘(paper-review):先审判情绪→再归因信号→迭代建议(用户批准才升版本)。
每周一 16:05 漏斗日报附本周汇总。

## 7. 推送机制

- 唯一通道:企业微信群机器人(push.py wecom 通道),markdown 详细版 + K线图 base64 直发
- 每条推送末尾强制 `<@在路上>`(强通知,不允许静默)
- 颜色语义:🔴上涨/走强/做多 🟢下跌/转弱 🟡观望/需确认
- 息知/serverchan 已暂停(Key 仍在本机,可恢复)
- 铁律:单轮任务只跑一次(2026-09-30 日内双推事故教训);输出先落文件再分段读

## 8. 数据铁律(事故换来的)

1. 一次多个 code,不密集连发;同花顺/东财批量历史拉取间隔≥30分钟(upstream_throttle.json)
2. A股日K终值 15:30 后取(15:35 cron),以 sina ticktime 验证
3. bars.py get_bars 是唯一读口;ensure_bars 查缺口只拉一次入库
4. 数据不可验证时 fail-closed:不新开仓,不瞎写
5. 回测与归因严格 point-in-time;20–30 笔干净样本前不谈"底层逻辑"
