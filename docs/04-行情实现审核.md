# 2026-10-08 Easy Stock 行情实现审核

结论：本地修复通过针对性验证，生产效果待部署后核验。审核范围为近期持久化行情页面、后台状态页、Go 日线与外置 SQLite、Python 三市场回补、Docker 回补连接与现有发布脚本；不涉及其他股票项目或交易执行。

## 已修复问题

- 长列表把右侧走势图推离视口：列表限高并独立滚动。浏览器使用 101 个模拟标的验证，选择第 99 行时走势图仍在视口；搜索代码同步右侧详情。
- 前端统一行情读取失败时没有尝试读取本地日线：补充本地数据库读取降级；手动刷新失败保持已有日线与走势图。
- Go 默认 A 股提供者被用于美股和币圈网络刷新：海外日线按市场选择 Yahoo 或 Binance / Kraken，通过相同的行情网络代理传输层。日线只返回已完成交易日；手动落库仍检查 OHLC、陈旧标志与最新应到日期。
- 宿主机 A 股历史回补固定连接回环端口：回补包装脚本动态读取 API 在指定 Docker 网络上的地址，并传入 `EASY_STOCK_API_URL`。
- 强制刷新仍可能从 Go / Python HTTP 缓存返回陈旧数据：强制请求失败直接报告错误；普通读取仍允许既有本地缓存降级。
- A 股回补历史缺口未解决仍退出成功：返回非零状态，让包装脚本记录失败。
- 结束摘要覆盖具体上游错误：保留最后具体错误，退出码摘要不再覆盖它；手动重试逐标的显示失败原因。
- Python 美股落库缺少完整日线和数值验证，异常时连接未保证释放：复用 OHLC 校验并限制到已完成美股交易日，补充事务回滚及连接关闭。
- 行业行情主源返回空结果且无错误时未选用非空备用源：空结果参与回退判定，避免返回空白行情。
- 两个回归测试问题：补充 SQLite 关闭，避免 Windows 文件锁；并发下限按实际交易日数量计算，避免国庆假期只有一个交易日时误报。

## 新增代理与重试

- UI：后台状态看板的盘后自动回补面板提供代理保存，以及 A 股、美股、币圈跟踪标的重试。
- API：`GET /api/v1/market-data/network` 读取；`PUT` 保存；使用现有 API 身份校验。
- 配置：共享数据库同目录的 `market-network.json`；Go 原子替换文件，Python 后续请求读取相同配置；没有新增第三方依赖。
- HTTP / HTTPS 无凭据代理，留空直连。用户须先保存，再重试；地址必须同时可由 API 容器与宿主机访问。
- 重试顺序执行逐标的强制刷新，单次后端刷新有 45 秒上限；失败不覆盖已存行情，界面退出时取消后续请求。
- 手动重试更新行情库，定时任务记录保持原记录，避免把手动刷新伪装成 cron 成功。

## 全后端测试剩余限制

- `TestStorePersistsSecretsWithPrivatePermissions`：Windows 文件模式为 0666，测试要求 Unix 0600；不能用该结果确认 Linux 部署文件权限。
- `TestSandboxSiteCustomizeBlocksHostFilesAndSubprocesses`：Windows 沙箱测试命令返回 9009；需要支持该沙箱的运行环境验证。
- 未运行依赖实时行情的可选线上测试；模拟验证不能替代生产代理连通性、上游限流和定时任务核验。
