# 桌面桥 Web 闭环与会话恢复

## 实现范围

本次 source 仓库提交覆盖 Web/API 与桌面桥之间的 Codex 对话闭环、桥名录、自动选桥、全链路检测、对话记录保留及相关页面适配。桌面端 Python worker 与管理器改动在外层 `pyQuant3` 仓库的 `bde25812` 中；两个仓库共同构成本次桥闭环改动。

## 功能改动

### 后端桥名录与选桥状态

- HMAC 桥可只读查询已登记桥名录；响应包含 Web 对话目标、策略研究目标、默认联动节点、桥心跳状态及 Web 对话运行/排队数量。
- 以 90 秒心跳窗口判断在线，并区分未登记心跳、状态不可读和离线；响应不缓存。
- Web 对话只使用在线且模型目录可用的 Codex 桥。原选择仍可用时保持原选择；离线时优先默认 ATS 工作区的可用桥，再按候选桥回退，并在页面提示节点/工作区短标识。
- UI 将长 node/workspace ID 显示为可辨识短标识；完整 ID 保留在实际配置和诊断信息中。

### 全链路检测与任务可靠性

- 设置页检测针对当前选择的桥、模型和推理强度提交固定检测任务；页面展示后端排队、桥领取、app-server 启动、工作区和 thread 准备、Codex 回复、回执写回阶段及等待时间。
- 检测有总时限和排队时限，超时后请求取消并区分“后端已确认终态”与“取消未确认”。终态检测任务及关联临时会话在客户端确认后清理。
- 后端延长运行任务租约，结果写回阶段缩短租约；相同租约的相同终态回执按幂等成功处理，避免响应丢失后重试被误判为租约失效。
- 任务查询对网络超时、连接失败及 HTTP 408/429/5xx 进行有限重试；用户主动停止时会发送取消请求并保留取消结果提示。

### AI 对话记录及页面行为

- 对话和当前会话 ID 保存在浏览器 `localStorage`；升级时迁移旧存储键。最多保留 30 个会话、每个会话最多保存 100 条消息。
- 页面切换或重启时，将未完成的回答标记为中断，保留已收到的部分内容；提供删除单个会话和确认后清空全部本机历史的操作。
- 侧栏使用动态视口高度并允许纵向滚动；会话栏增加清空入口，避免窗口高度不足时无法访问设置或底部操作。
