# 2026-10-10 SBC 配色、标记与分时 VWAP 对齐

- 对照 ATS `ats/ui/intraday_strategy_dialog.py`：分时价格 #00B4D8 实线，VWAP #FFD700 虚线；日线红涨/青跌、分时量柱红涨/绿跌；通道白色上下轨、淡白虚线中轨，MA5 金黄、MA20 品红。
- 九转过滤 1～3 噪声，4～8 使用粉/绿文字，9 使用深底胶囊；启动使用粉色框，逃顶使用金色框。相隔不超过 4 根的信号聚类显示首尾计数和中间微箭头，不再按固定像素间距丢弃信号。
- 黄金阶梯按 80.9% 橙、61.8%/38.2% 金、50% 青、19.1% 绿显示。补充右侧关键价位、低点支撑虚线及局部极值价格筛选。
- 图表区域固定 SBC 深色底和调色板，页面其余区域保持既有主题。
- 删除分时 20 点简单均线，Go 在完整分钟数据上先排序、按交易日累计计算 VWAP，前端缩放仅裁切显示，不重新计算均价。
- Go 行情新增可选字段 `vwap`、`vwap_estimated`，保持旧 API 兼容。东方财富成交量按手转换为股；新浪按股处理。未知来源/缺少成交额时用收盘价与成交量累计估算，并在图例及价位明确标注“估算”；无有效成交量不伪造均价。
- 分时额外加载日线 SBC 分析以显示上轨、反转、支撑和目标，界面明确标为“日线关键价位参考”，不将其伪装成分钟策略。
- 分时纵轴随可见价格、VWAP 与附近关键价位自适应；0% 基准固定昨收，缺少昨收时明确标注首根开盘基准，缩放不改变基准。
- 验证：Go SBC/HTTP 回归通过，新增 VWAP 单位、缺失成交额估算、跨日重置、零/异常成交量测试；前端相关 10 项测试通过，生产构建及类型检查通过。
- 边界：分钟数据不是逐笔成交，缺少真实成交额时只能提供明确标注的量加权估算；跨日/多日 VWAP 阶梯未在本轮虚构。线上行情日期和陈旧状态仍以数据源为准。

## 分时图层隔离补充
- 线上切股复核发现日线分析曲线会被额外叠加到分时主图，已限制日线图层仅在日线/分钟 K 线模式显示；分时只绘制价格、VWAP、成交量和明确标注的日线水平参考。
- 分时默认展示当日全部可用分钟数据，缩放及回到最新保留右侧最新锚点。
- 新增 3 项组件回归：分时不能包含日线图层、日线保留指标图层、分时默认显示完整 238 根示例数据；本轮相关测试累计 13 项通过。
