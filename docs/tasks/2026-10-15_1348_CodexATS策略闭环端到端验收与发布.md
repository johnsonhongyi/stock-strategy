## 分析、决策、执行、复盘

1. **分析任务**：既有 Python worker 调度盘前、盘中、盘后研究；每十五分钟定期研究，原门禁确认可入场但 AI 提案过期时受限补发研究，新增平仓即时触发复盘。不复制 feed-pulse/heartbeat 系统任务。
2. **桌面协同**：独立 Windows 桥复用现有 JSON IPC 网关与 HMAC 身份协议，使用本机已登录 Codex app-server。公开的动态工具仅提供市场上下文、池内个股证据、ATS 持久化 IPC 证据；每次调用记录工具、时点与证据哈希。
3. **研究会话**：同日同工作区续接本集成自己的研究会话，桌面 Codex 可直接读取；会话命名为“Muse模拟策略研究 YYYY-MM-DD”。不会接管用户其他聊天。当前共享 control socket 不可用，采用本机官方 app-server，与桌面共享持久化研究历史；不宣称连接了不存在的共享 daemon。
4. **提案准入**：模型输出市场/轮动判断、回答和逐股 observe/follow/avoid 条件计划。结构、股票范围、已知证据引用、价格区间、缺口及时效均须通过验证。Shadow 记录实际对照；Enforce 为新开仓增加有效 AI 提案约束，原 P4/P8/P25、市场、现金、仓位、时间窗、T+1 和风险门仍独立复核。
5. **唯一执行入口**：模型不调用券商、不直接写账户。最终模拟成交保留 AI 任务 ID、证据哈希及 Codex thread ID，现金/持仓与原账本事务一起落盘。
6. **退出与复盘**：T+1 锁定事件带交易/提案引用；原止盈止损等退出优先于新买和 AI 传输。新增平仓自动发起 AI 复盘，复盘单独保存在 ai_review，不能覆盖入场 ai_latest，也不自动修改策略参数。
7. **可视闭环**：前台展示 AI 任务、自由提问、桌面在线、模式、逐股提案、执行引用和独立复盘；显示缺数据、拒绝、超时与模型错误，不以分析成功冒充成交成功。

## 可靠性修复

- 领取任务使用单次 SQL CAS，竞争领取只有一个租约持有者；过期租约、旧 token、跨节点及冲突回传拒绝；相同结果回传幂等。
- 任务有截止时间、固定 node/workspace 和证据哈希；空提案/无效会话不能伪装完成，语义非法结果不能进入执行。
- AI 队列或模型异常不会回滚已经完成的模拟退出；保留原风险监控并记录 AI_ERROR。
- 桌面有超时、中断、输出限额、进程树清理、运行时单实例锁、结果持久化和失败冷却；回传丢失可复用已完成结果，不能把已计算成功改报模型失败。
- 明确关闭 SQLite 只读连接，修复 Windows 文件句柄占用；连板股同时命中当日题材领涨成员时保留有效题材归属。
- 项目级 .gitignore 排除日志、构建缓存、账户、IPC 密钥和环境文件；独立桥的配置不覆盖用户 global.ini 或其他会话的 TK/ATS 修改。
