# 2026-10-10 SBC 图表交互与异常恢复更新

## 本次变更
- 后端保持 Go 原生实现，增加 2D、3D 交易日聚合；按已有 ATS 顺序从最早日线分组，保留末尾不足周期的组合，合并 OHLC、成交量、成交额和来源陈旧状态。
- SBC 输入允许同一证券的规范化代码别名，同时保留不同证券、错误 OHLC、时间戳和非有限值校验。
- 小图和放大图共用周期、图层及完整序列分析接口，支持分时、5/15/30/60 分、日线、2D、3D、周线、月线；实际可用历史范围由数据源决定。
- 支持滚轮缩放、Shift+滚轮平移、拖动历史、回到最新；默认缩放以右侧最新数据为锚点，历史平移需主动触发。
- 右上角入口打开可调整大小的弹窗，支持最大化/还原、关闭、Esc、焦点约束及大小自动持久化。
- 详情框默认置于图下并展示最新行情，悬浮选择历史点后保留明细；通过手柄拖动，按小图/放大图分别保存相对位置，可一键移回图下。
- 趋势题材个股列表独立滚动、表头固定，右侧详情在桌面布局内保持可见；列表与图表支持上下键、上下按钮同步切股，选中行自动进入列表可视区。
- 完整成分异常为空时保留已知领涨预览，并明确提示完整成分暂不可用。
- 初始空行情或 SBC OHLC/时间戳/证券代码异常，对同一证券和周期自动尝试更新一次；复用现有行情刷新校验和持久化接口。失败保留错误和手动重试，不循环刷新、不删除缓存库。
- 异步请求切换证券和周期时取消旧请求，并按配置/证券/周期区分响应，防止旧结果覆盖当前视图。

## 使用与后续边界
- 拖动详情允许用户主动覆盖图表；“移到图下”清除该视图保存的位置。浏览器禁用本地存储时仍可使用拖动和调整大小，但刷新后不能恢复。
- 只调整图表、数据修复和查看行为，没有修改下单、风控或执行逻辑，也没有给后端 Docker 增加 Python 环境。
- 现有 ATS 公式对照测试仍是算法一致性的依据；未声称实现 SBC 全部终端功能。分时 VWAP 扩展、终端专用交互和执行/回测入口仍需另行明确范围及建立对照用例。
- 数据源仍可能无对应分钟周期或返回陈旧数据；来源与日期继续展示，不能把界面恢复等同于行情完整性已验证。
